# Adding a Product

This guide explains how to add a new product to the Price Tracker so the monitor can watch it for price changes.

## Where Products Are Defined

All monitored products are defined in `data/products.py` as Python objects. Storing products as typed objects (instead of JSON or dictionaries) gives you:

- IDE autocomplete
- Type checking
- Clear version control diffs
- Easy discovery of available fields

## Basic Steps

1. Open `data/products.py`.
2. Add a new `Product(...)` entry to the `PRODUCTS` list.
3. Fill in at least the required fields.
4. Set a `target_price` if you want email alerts.
5. Save the file and run `python app.py`.

## Required Fields

Every product must have these fields:

| Field | Example | Purpose |
|-------|---------|---------|
| `id` | `"dell-xps-15-001"` | Stable unique identifier. Never change this once set. |
| `name` | `"Dell XPS 15"` | Human-readable name used in notifications. |
| `listings` | `[ProductListing(...)]` | One or more retailer listings (site + URL + parser config). |

## Optional but Useful Fields

| Field | Default | Purpose |
|-------|---------|---------|
| `brand` | `None` | Product brand, e.g. `"Dell"`, `"Apple"`. |
| `category` | `None` | Category for grouping, e.g. `"laptops"`. |
| `currency` | `"AUD"` | ISO 4217 currency code. |
| `enabled` | `True` | Set to `False` to temporarily stop monitoring. |
| `target_price` | `None` | Email fires when current price ≤ this value. |

## Full Example

```python
from decimal import Decimal

from models.listing import ProductListing
from models.product import Product
from models.site import Site

PRODUCTS: list[Product] = [
    Product(
        id="dell-xps-15-001",
        name="Dell XPS 15",
        brand="Dell",
        category="laptops",
        currency="AUD",
        enabled=True,
        target_price=Decimal("2499.00"),
        listings=[
            ProductListing(
                id="dell-au",
                site=Site(name="Dell Australia"),
                url="https://www.dell.com/en-au/shop/laptops/xps-15/spd/xps-15-9530-laptop",
                price_selector=".ps-dell-price",
                currency="AUD",
            ),
        ],
    ),
]
```

## How to Find the CSS Selector

The hardest part is usually finding a reliable CSS selector for the price element.

### Using Chrome / Edge / Firefox DevTools

1. Open the product page in your browser.
2. Right-click on the price and select **Inspect**.
3. The DevTools panel will open and highlight the HTML element containing the price.
4. Right-click the highlighted element.
5. Choose **Copy → Copy selector**.
6. Paste the copied selector into `price_selector`.

### Example

If the HTML looks like this:

```html
<span class="price-current">$1,999.00</span>
```

You can use any of these selectors:

```python
price_selector=".price-current"
price_selector="span.price-current"
price_selector="#product-price"
```

Prefer the simplest selector that uniquely matches the price element.

## Tips for Reliable Selectors

- **Avoid overly long generated selectors** like `#root > div > div:nth-child(3) > span` if a class name is available.
- **Prefer class names** that clearly describe the price, e.g. `.product-price`, `.current-price`, `.price`.
- **Test the selector** in the browser console with `document.querySelectorAll(".your-selector")`.
- **Avoid selectors that include dynamic IDs** or A/B test class names.
- **Use attribute selectors** only when class names are obfuscated, e.g. `[data-testid="price"]`. These are usually more stable than autogenerated class names.

## Common Selector Patterns

| Site Style | Likely Selector |
|------------|-----------------|
| Simple class name | `.price` |
| Sale/current price | `.current-price` |
| Product detail page | `.product-price .amount` |
| Data attribute | `[data-testid="product-price"]` |
| Nested structure | `.product-info .price-current` |

## What If the Price Is Not in the HTML?

Some websites load prices with JavaScript or embed them inside JSON in a `<script>` tag. In those cases, a CSS selector will not work.

### Signs of a JavaScript-rendered price

- The price appears in the browser but not when you use **View Source**.
- The price lives inside `window.__PRELOADED_STATE__` or a similar JSON blob.
- The HTML element is empty until the page finishes executing JavaScript.

### Example: Uniqlo

The Uniqlo product page stores prices inside `window.__PRELOADED_STATE__`:

```json
{
  "entity": {
    "pdpEntity": {
      "E479525-000-00": {
        "product": {
          "prices": {
            "base": { "value": 49.9, "currency": { "code": "AUD" } },
            "promo": { "value": 39.9, "currency": { "code": "AUD" } }
          }
        }
      }
    }
  }
}
```

For sites like this, you need a **JSON parser** or a **Playwright-based client**. Both can be added later without changing the monitor service or business logic.

## Enabling and Disabling Products

Set `enabled=False` to keep the product in the catalog but skip it during monitoring:

```python
Product(
    id="old-laptop-001",
    name="Old Laptop",
    enabled=False,
    listings=[
        ProductListing(
            id="example",
            site=Site(name="Example Store"),
            url="https://example.com/old-laptop",
            price_selector=".price",
        ),
    ],
)
```

This is useful when:

- A product is temporarily out of stock.
- A site redesign broke the selector and you want to fix it later.
- You want to keep historical context without active monitoring.

## Setting a Target Price

The `target_price` field controls when email notifications are sent.

```python
target_price=Decimal("1999.00")
```

A notification is sent when:

```
current_price <= target_price
```

If `target_price` is `None`, no notification is sent for that product.

## Testing a New Product

After adding a product, run the monitor manually:

```bash
python app.py
```

Watch the logs. If the selector is wrong, you will see an error like:

```text
Selector '.wrong-selector' matched no elements for product dell-xps-15-001
```

If the price text is messy (e.g. includes words like "inc. GST" or "Save $300"), the parser will still try to extract the last numeric value it finds.

## Best Practices

1. **Use one product per URL** — do not reuse the same `id` for different variants.
2. **Keep IDs stable** — changing an `id` breaks continuity if you later add price history.
3. **Set realistic target prices** — set the threshold to a price you would actually buy at.
4. **Start with `enabled=True`** for only a few products while you verify selectors.
5. **Use `Decimal` for prices** — this avoids floating-point rounding errors.
